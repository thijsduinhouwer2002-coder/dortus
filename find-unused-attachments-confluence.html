How to find unused attachments in Confluence Cloud

Spaces collect files: images that were removed from the text but stayed attached, old exports, earlier versions of the same document. Confluence can list them. It cannot tell you which ones are still shown or linked anywhere.

Why unused files stay behind

Removing an image or a file link from a page does not remove the attachment: the file stays attached to the page. Uploading a new version of a file keeps the older versions as well. And a file attached to one page can be shown or linked on another page, so the page it belongs to tells you little about where it is used.

The manual way: Confluence's own attachments list

Atlassian's documentation (Manage uploaded files) gives this path to all files in a space:

  1. Go to the space.
  2. Next to the space name in the sidebar, select More actions (•••), then Space settings.
  3. In the settings sidebar, under Content, choose Attachments.

The Attachments page lists the files attached in the space, with the columns Name, Size, Creator, Creation Date, Last Modification Date, Labels and Attached To (for example "Page: …" or "Blog: …"). At the top you can narrow the list with Filter By File Extension and Filter By Label. Each page also has its own list of attachments.

None of these columns says whether a file is used. Attached To tells you where a file hangs, not whether it is displayed or linked on its own page, on another page, in a blog post or in a comment. To find out, you open the pages and look. For a handful of files that works. For hundreds of files across hundreds of pages it does not, and a file that looks forgotten may still be shown on a page you did not open.

A faster way: AttachClean

Full disclosure: Dortus makes AttachClean, a read-only report that checks the pages, blog posts and comments of a space that you can view, and shows for each attachment where it is used.

  1. Install AttachClean from the Atlassian Marketplace (Confluence admin).
  2. Open a space where you are a space admin. In the space sidebar, under Apps, click Unused attachments.
  3. Click Scan this space. You see the progress while it runs; you can cancel at any time.
  4. Use the filters All, Unused, Old versions only, Used. The column Found in shows where each used file appears.
  5. Click Export CSV to review the list in Excel before you delete anything yourself.

Only space admins can run the scan.

What AttachClean does not do

  • It deletes nothing. It also changes and moves nothing. Deleting stays a decision you make in Confluence yourself.
  • Drafts and templates are not checked.
  • It only sees what you can see. Unused means: not shown or linked on any page, blog post or comment that you can view. A file that people only download from the page's attachment list also counts as unused.

How to write LaTeX math in Confluence Cloud

Confluence Cloud has no built-in LaTeX: a formula you type, such as \frac{a}{b} or $x^2$, stays plain text. To put math on a page you have three options: an image of the formula, a code block with the LaTeX, or a Marketplace app that draws LaTeX on the page.

Published 30 October 2026

Does Confluence Cloud support LaTeX?

No. Confluence Cloud has no LaTeX engine of its own, so the editor does not turn LaTeX or dollar signs into an equation. That leaves the three options below. The first two work today without installing anything.

Option 1: an image of the formula

Draw the formula with any LaTeX tool (an online equation editor, or LaTeX on your own computer), save it as PNG or SVG, and upload the image to the page.

  • Readers see a real equation, in every browser and in exports.
  • Nobody can edit it on the page. To change one symbol, someone has to find the LaTeX, draw it again and replace the image.
  • The text is lost. Search and screen readers see only the image, unless you add alt text.

If you go this way, put the LaTeX in the image's alt text or in a code block under it, so the next person can redraw it.

Option 2: a code block with the LaTeX

Insert a code block (type /code in the editor) and paste the LaTeX into it.

  • The source is safe and easy to copy. Anyone can take the LaTeX into another tool.
  • Readers see code, not an equation. Fine for a team that reads LaTeX, hard for everyone else.

This suits technical notes where the formula is reference material, not something people need to read at a glance.

Option 3: a Marketplace app that draws LaTeX

Several apps on the Atlassian Marketplace add a LaTeX macro to Confluence Cloud: you type LaTeX, and the page shows the equation. Points worth comparing:

  • A preview while you type, and a clear message when the LaTeX has a mistake.
  • Inline formulas, inside a sentence, as well as equations on their own line.
  • Where the formula is drawn: in the reader's browser, or on the vendor's servers.
  • PDF and Word export: try it on a test page if you rely on it.

Five common formulas in LaTeX

Copy the code into any LaTeX tool or app, without dollar signs. Each formula is shown under its code.

Quadratic formula

\frac{top}{bottom} is a fraction, \sqrt{…} a square root, ^ a power and \pm plus-or-minus.

Mean of a list of numbers

\sum_{from}^{to} is a sum, _ a subscript and \bar{x} a bar over the x.

\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i

Integral

\int_{0}^{\infty} is an integral from 0 to infinity. \, adds a thin space before dx.

\int_{0}^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}

Matrix

Inside pmatrix, & separates columns and \\ starts a new row. \quad is a wide space.

A = \begin{pmatrix}
  a & b \\
  c & d

cases puts the options under each other with one brace. \text{…} writes normal words inside a formula.

Which option fits

One formula that will never change: an image, with the LaTeX saved next to it. A formula as reference for people who read LaTeX: a code block. Formulas that people read at a glance and keep editing on the page: a Marketplace app.

FAQ

Can I type $x^2$ in a Confluence page?

You can, but Confluence shows it as typed, dollar signs included. For a simple power or index, Unicode characters such as x² or H₂O work in normal text. For anything more, use one of the three options above.

Do I need to know LaTeX?

A few commands go a long way: ^ for a power, _ for a subscript, \frac{a}{b} for a fraction and \sqrt{x} for a square root. The five formulas on this page cover most of what people write. KaTeX keeps a full list of supported commands.

Can ChatGPT or Claude write the LaTeX for me?

Yes. Describe the formula in words and ask for the LaTeX only, without dollar signs. Check the result in a preview before you publish: an assistant sometimes uses a command your tool does not support.

Can I write chemistry formulas?

Yes, with the mhchem commands \ce and \pu, if your LaTeX tool supports them. Math for Confluence does, for example \ce{CH4 + 2 O2 -> CO2 + 2 H2O}.

Is Math for Confluence available now?

Not yet: it was submitted to the Atlassian Marketplace on 30 October 2026 and is waiting for approval. Until then, an image or a code block works without an app.

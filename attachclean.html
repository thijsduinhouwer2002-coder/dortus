AttachClean · Confluence app

Unused attachments in a Confluence space, in one report.

See which files in a Confluence space are not shown or linked on any page, blog post or comment you can view, and where the others are used. A read-only report for space admins: nothing is moved or deleted.

Getting started

  1. Install AttachClean from the Atlassian Marketplace (Confluence admin).
  2. Open a space where you are a space admin. In the space sidebar, under Apps, click Unused attachments.
  3. Click Scan this space. You see the progress while it runs; you can cancel at any time.
  4. Use the filters All, Unused, Old versions only, Used. The column Found in shows where each used file appears.
  5. Click Export CSV to review the list in Excel before you delete anything yourself.

Only space admins can run the scan.

Need help? Email support@dortus.com.

How AttachClean decides

A file counts as used when it is shown or linked on its own page, on another page, in a blog post, in a comment or inline comment, on a page in another space, or as a page's header image.

Unused means: not shown or linked on any page, blog post or comment that you can view. A file that people only download from the page's attachment list also counts as unused.

Old versions are counted separately: Old versions only means the file is used, and older versions of it are kept as well.

If some pages in the space cannot be read with your permissions, the report says how many, and files with no use found are marked Not found instead of Unused.

Drafts and templates are not checked.

See also: How to find unused attachments in Confluence Cloud

Read-only

AttachClean changes, moves or deletes nothing. It reads pages, blog posts, comments and attachment details in your browser, with your own Confluence permissions. It stores nothing and sends nothing outside Atlassian.

How to put an Outlook email on a Confluence page

A customer request for the project page, the approval behind a decision, the alert that started an incident: sooner or later an email belongs in Confluence. Confluence Cloud has no built-in way to take an email from Outlook, so people ask about it on Atlassian Community again and again. These are the four ways that work, with what each one keeps and what it loses.

Written on 14 October 2026 from the Atlassian and Microsoft pages and tickets linked next to each step. Menu names change now and then, so if your Outlook or Confluence looks different, go by the linked page.

Some of the Community questions this guide answers: “how do upload an email on confluence page”, “Embed Outlook email.msg file into a confluence page” and “I am uploading an outlook mail in .msg format in confluence page and there is no preview” (Atlassian Community).

First: save the email as a file

Options 2, 3 and 4 below start with the email as a file. Outlook can do that without any add-in (Microsoft: Save an Outlook message as a .eml file, a PDF file, or as a draft):

  • Classic Outlook for Windows. Open the email, choose File → Save As and keep the default type. That gives an Outlook .msg file.
  • New Outlook for Windows. Open the email, choose More actions (the three dots) and then Save as. Microsoft says the file is saved as an .eml or .msg file.
  • Outlook on the web. Select the email, then More actions → Download.

Dragging straight from Outlook into Confluence is not reliable. Atlassian's ticket says dragging an email from the Outlook client on Windows into Confluence Cloud “doesn't work all the time”: sometimes nothing uploads and there is no error. Its workarounds are to drag the email to the desktop first and then into Confluence, or to use Forward as attachment and drag that attachment. Atlassian closed the ticket in May 2025 without a change (Atlassian: CONFCLOUD-76968). From the new Outlook, a drag to a folder gives an .eml file, not a .msg (Microsoft Q&A: Outlook: drag and drop to Explorer saves email as a .eml file not a .msg file).

Not sure which format to keep? Outlook .msg vs .eml explains the difference.

Option 1: copy and paste the text into the page

Open the email in Outlook, select the text, copy it and paste it into the page in the Confluence editor.

  • What you get. The words become part of the page, so anyone who can read the page can read them, and Confluence search finds them like any other page text.
  • Images may not come along. Atlassian's ticket on pasting text with images from Word, OneNote or Google Docs says the text usually comes through but images often do not, and that copy and paste from other formats is not a supported feature. Upload the images separately if you need them (Atlassian: CONFCLOUD-77928).
  • Attachments don't come along. Copying or dragging an attachment straight from Outlook into a page is an open request (Atlassian: CONFCLOUD-28812). Save each attachment from Outlook and upload it to the page.
  • It is a copy, not the email. Only what you selected ends up on the page. The sender, date and recipients are there only if you copy them too, the technical headers never are, and anyone who can edit the page can change the text.

Option 2: save the email as PDF and attach it

Outlook has no PDF type under Save As. Print the email instead and choose Microsoft Print to PDF as the printer (Microsoft: Save an Outlook message as a .eml file, a PDF file, or as a draft). Then insert the PDF in the page: drag it in, or type /files (Atlassian: Display files and images).

  • What you get. The email as it looked on screen, with its images, in a file that anyone can open.
  • How it shows on the page. As a small inline tile or as a thumbnail. Readers click Preview to read it without downloading, or Download it (Atlassian: Work with images, videos, and files). The PDF macro that showed a PDF's pages on the page is only available in the legacy editor (Atlassian: Review macros only available in the legacy editor).
  • It is a printout, not the email. The PDF holds what Outlook printed: no technical headers, and the attachments of the email are not in it.
  • It can be blocked. If your organisation requires sensitivity labels, Print to PDF can be blocked in Outlook (Microsoft: Print to PDF is blocked if Mandatory Labeling is enabled).

Option 3: attach the .msg or .eml file

Save the email as a file (see above) and drag it into the page, or type /files. You need the Add Attachments permission in the space, and by default a file can be up to 100 MB (Atlassian: Upload a file).

  • What you get. The original email: sender, recipients, date, the technical headers and the attachments inside it are all kept in the file.
  • What readers see. A file on the page, not an email. Confluence Cloud has no email view: previewing .msg files is an open request (Atlassian: CONFCLOUD-74736), and so is showing attached email files on the page, for .msg and .eml (Atlassian: CONFCLOUD-41597). On Community, the answer to the .msg question above is that previewing .msg files is currently not supported on the cloud.
  • Reading it means downloading it. Atlassian's workaround is to download the file and open it in Outlook. Readers without Outlook, on a Mac or a phone, may not be able to open a .msg at all. How to open .msg and .eml email attachments in Confluence covers the ways to read them.

Option 4: attach the file and show it with MailView for Confluence

Full disclosure: Dortus makes MailView for Confluence. It shows an attached .msg or .eml file as a readable email on the page. You still do option 3 first: MailView does not take the email out of Outlook, it reads the file that is attached to the page.

  • Show one email on the page. Edit the page, insert the Email (MailView) macro, choose the attachment and click Save. The email shows in the editor and, after you publish, for readers of the page: sender, recipients, date, the message as it was sent with its inline images, and the files inside it.
  • All emails of the page. Emails on this page, under the page title, lists every email attachment of the page. Click one to read it in a large view.
  • A phishing check. Each email you open gets a verdict: Looks OK, Be careful, Likely phishing or Not enough to judge, with the reasons. It can miss things, so treat Looks OK as “nothing suspicious found”.
  • PDF and Word export. When you export the page, the macro becomes a plain version of the email: subject, sender, recipients, date, the verdict line, the text without earlier replies, and the names of the attachments. Very long emails are shortened.
  • What it does not do. It does not add the email text to the page, so Confluence search does not find it. Files over 10 MB and protected Outlook messages (.rpmsg) get a download link instead. Confluence Cloud only.
  • Privacy. It only has read access to attachments. The email is shown in the reader's browser; nothing is stored and nothing is sent outside Atlassian.

The details, limits and documentation are on the MailView for Confluence page.

Not in Confluence Cloud: sending an email to a page

Confluence Cloud has no address you can send or forward an email to so that it lands on a page. Creating pages from emails is an open request (Atlassian: CONFCLOUD-1726), and a newer request for “Email into Confluence” says the feature is only available for Confluence Server and Data Center (Atlassian: CONFCLOUD-79455). That is the mail archive of Data Center, which collects email in a space (Atlassian: Mail Archives).

Only the text matters, and only for this page? Copy and paste. The email is evidence (a complaint, an approval, a phishing report) or people will need it again? Attach the file, so the original stays with the page, and add a viewer if readers should not have to download it.

Short answers

Can I drag an email from Outlook straight onto a Confluence page? Sometimes. It does not always work, and a failed drop shows no error. Drag it to the desktop first and then into the page (Atlassian: CONFCLOUD-76968).

Can I forward an email to Confluence Cloud? No. Confluence Cloud has no email address for pages or spaces (Atlassian: CONFCLOUD-1726).

Does Confluence Cloud show .msg or .eml files as an email? No. Both stay files; previewing them is an open request (Atlassian: CONFCLOUD-74736, CONFCLOUD-41597).

.msg or .eml? Both can be attached. Classic Outlook saves .msg; the new Outlook and Outlook on the web save files you download. Outlook .msg vs .eml explains which keeps what.

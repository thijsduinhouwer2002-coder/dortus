AttachClean · Confluence app

Getting started

AttachClean shows space admins which attachments in a Confluence space are not shown or linked on any page, blog post or comment they can view, and how much space those files take up. It only reads: nothing is moved or deleted.

  1. Install AttachClean from the Atlassian Marketplace (Confluence admin).
  2. Open a space where you are a space admin. In the space sidebar, under Apps, click Unused attachments.
  3. Click Scan this space. You see the progress and the time left while it runs; you can cancel at any time.
  4. When the scan is done, the line at the top tells you how much space the unused attachments take up, and how much the older versions of files in use take up.
  5. Use the filters All, Unused, Old versions only, Used. The column Found in shows where each used file appears.
  6. Click Export unused (CSV) or Export CSV to review the list in Excel before you delete anything yourself.

Only space admins can run the scan. Other people see one line asking them to contact their space admin.

What the statuses mean

  • Unused: not shown or linked on any page, blog post or comment you can view. A file that people only download from the page's attachment list also counts as unused.
  • Old versions only: the file is in use, but older versions of it are kept as well.
  • Used: the file is in use and has no older versions.
  • Not found: no use was found, but some pages in the space could not be read with your permissions. The report says how many. The file may be used there.
  • Not checked: the scan was stopped before this file was checked.

A file counts as used when it is shown or linked on its own page, on another page, in a blog post, in a comment or inline comment, on a page in another space, or as a page's header image.

What is not checked

Drafts and templates are not checked. Whiteboards, databases and the trash are not checked either. Pages you cannot view are not checked: the report is based on what you can view.

Export

Export unused (CSV) downloads the unused files, biggest first, with file, size, page, upload date and uploader. Export CSV downloads the rows of the current filter. The file is made in your browser.

Big spaces

AttachClean checks up to ten pages at a time. Above 5,000 attachments it warns you first, because the scan can take several minutes. If you cancel, the report keeps what was checked, and Continue scan picks up where it stopped.

Data and permissions

AttachClean runs on Atlassian Forge. It has no backend and stores nothing: the report exists only while the page is open. All requests go from your browser to your own Confluence site, with your permissions. Nothing is sent to Dortus or to any third party. See the privacy policy.

It uses these read-only permissions:

  • read:space:confluence: the space name, and whether you are a space admin.
  • read:page:confluence: pages and their content, to find where files are used.
  • read:blogpost:confluence: the same for blog posts.
  • read:comment:confluence: comments, because an image in a comment counts as use.
  • read:attachment:confluence: the attachments, their sizes and their versions.
  • read:user:confluence: the name of the person who uploaded a file.
  • search:confluence: a quick estimate of the space size before the scan.

AttachClean · Confluence app

Getting started

  1. Install AttachClean from the Atlassian Marketplace (Confluence admin).
  2. Open a space where you are a space admin. In the space sidebar, under Apps, click Unused attachments.
  3. Click Scan this space. You see the progress while it runs; you can cancel at any time.
  4. Use the filters All, Unused, Old versions only, Used. The column Found in shows where each used file appears.
  5. Click Export CSV to review the list in Excel before you delete anything yourself.

Only space admins can run the scan.

Need help? Email support@dortus.com.

Your grammar and your scanner, as real languages.

Bison/Yacc grammars (.y, .yy) and Flex/Lex scanners (.l, .ll) get colors, syntax errors, a Structure view, go to definition and rename within a file, in CLion and other JetBrains IDEs. Made for C and C++ developers who write parsers and lexers.

What you can do

Without a plugin the IDE opens these files as plain text. With Bison & Flex they behave like the rest of your code.

  • Read it at a glance. Directives, tokens, rules, start conditions and regular expressions each get a color from your color scheme, in light, dark and any theme. You can change them under Settings, Editor, Color Scheme.
  • C code in actions. Keywords, strings, comments and $$, $1, @1 are highlighted inside { ... }.
  • See mistakes while you type. Syntax errors in the grammar and the scanner are marked in the editor.
  • Find your way. Fold rules and code blocks, and open the Structure view to see every rule, token and definition.
  • Jump and rename. Go to definition, find usages and rename a rule, token or start condition within a file.
  • Grammar and scanner together (Pro). Jump from a token in the .l scanner to its %token in the .y grammar, and find or rename a token in both files at once. Renaming a token that your scanner also uses changes both files, so it needs Pro.
  • Warnings for loose ends (Pro). A symbol in a rule that is neither a rule nor a token, a rule or token nothing uses (your scanner counts too), and start conditions that are undeclared or never used are flagged in the editor. A quick fix removes the unused ones.

Install

Once it is listed: open Settings, Plugins, Marketplace, search for Bison and press Install. If another plugin for .y files is installed, turn that one off, so the IDE uses one plugin for these files.

Privacy

Bison & Flex has no telemetry and sends nothing to Dortus. It reads the .y and .l files in your project to color them and to find rules and tokens. Files are only changed when you rename something or apply a quick fix yourself.

Licenses and trials go through JetBrains: the IDE checks your license with your JetBrains account, the same way it does for the IDE itself. JetBrains processes that data under its own privacy policy. JetBrains handles payment and invoices. If JetBrains shares buyer details with us as the seller, or you email us, we use them only for your license and for support.
